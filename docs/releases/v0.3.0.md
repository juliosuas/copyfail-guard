# CopyFail Guard v0.3.0 release notes draft

Draft prepared on 2026-06-18. Do not publish until the `v0.3.0` tag exists.

## Summary

CopyFail Guard v0.3.0 focuses on adoption, community validation, release readiness, and CI reliability. The core safety model is unchanged: CopyFail Guard is an interim mitigation and verification helper for CVE-2026-31431 "Copy Fail"; the final remediation remains vendor patched kernel plus reboot.

## Highlights

- Added clearer first-run trust signals in the README.
- Added contribution, support, pull-request, issue-template, and Dependabot metadata.
- Added fleet rollout guidance, Ansible example, and GitHub Actions seccomp validation example.
- Added community validation documentation and a Compatibility report issue template.
- Added sample outputs for `doctor`, `assess`, JSON automation, and AF_ALG socket validation.
- Added a release checklist for repeatable tagged releases.
- Added `--version` alias and `COPYFAIL_GUARD_REF` support for pinned installs.
- Hardened CI with concurrency, job timeouts, and non-interactive openSUSE GPG key handling.

## Safety model

This release still does not ship exploit code or destructive validation. Safe checks focus on:

- whether `algif_aead` appears available, loaded, built in, or blocked
- whether host mitigation is active
- whether `socket(AF_ALG)` is blocked inside a target runtime
- whether the remaining required action is unload, reboot, seccomp, or vendor patching

## Install

Pinned clone:

```bash
git clone --branch v0.3.0 --depth 1 https://github.com/juliosuas/copyfail-guard.git
cd copyfail-guard
sudo ./bin/copyfail-guard.sh doctor
sudo ./bin/copyfail-guard.sh assess
```

Pinned installer:

```bash
sudo env COPYFAIL_GUARD_REF=v0.3.0 ./scripts/install.sh
```

## Upgrade notes

- No breaking CLI changes are expected.
- `copyfail-guard version` and `copyfail-guard --version` should report `0.3.0`.
- Existing `mitigate`, `verify`, `rollback`, `seccomp-docker`, and `seccomp-patch` workflows are unchanged.
